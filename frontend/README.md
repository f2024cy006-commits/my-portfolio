# Portfolio Website

A clean React + Vite portfolio site starter, ready for you to customize with your own content, projects, and contact details.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`

## Notes

- Replace the placeholder data in the app with your real bio, project list, and contact information.
- Update the document title and meta description in `index.html`.
- Add your own assets and social links as needed.
